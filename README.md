
# English
# Date Difference Calculator C#
A simple and short console application written in C# to calculate the number of days between two dates.

## Usage
1. Run the program.
2. Enter the first date in `yyyy-MM-dd` format.
3. Enter the second date in `yyyy-MM-dd` format.
4. View the total number of days between the two dates.
